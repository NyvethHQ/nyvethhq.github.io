Open Source

Openness where it creates value.

“Nyveth believes software should be open when openness creates meaningful value for users, developers, and the wider ecosystem.”

Independent identity

Projects remain independently identifiable with dedicated architectures, roadmaps, and licenses rather than obscured under a monolithic brand.

Source availability

Source code is openly available where appropriate, allowing inspection, local execution, self-hosting, and deep technical auditing.

Documentation matters

Code is only as useful as its clarity. We invest in comprehensive architectural documentation, setup guides, and reproducible examples.

Engineering quality

Open source is not a dumping ground for prototypes. We apply the same rigorous testing, linting, and type discipline to all public repositories.

Community contributions

Contributions, feedback, and issue reports are actively welcomed and reviewed across our supported open-source projects.

About Nyveth

An independent software initiative building thoughtfully engineered tools and systems.

Nyveth is an independent software company focused on building useful software across developer tooling, engineering infrastructure, intelligent systems, and applications.

Operating as an independent software initiative, Nyveth maintains a portfolio of distinct, individually identifiable products. Each initiative is engineered with architectural autonomy, explicit design boundaries, and dedicated roadmaps, brought together under a shared commitment to software longevity, technical transparency, and genuine utility.

Independent Initiative

Self-directed engineering focused on shipping solid software rather than corporate growth metrics.

Product Autonomy

Each repository retains its own identity, license, and technical roadmap tailored to its domain.

Principled Architecture

Commitment to local-first architectures, transparent dependencies, and privacy-respecting designs.
